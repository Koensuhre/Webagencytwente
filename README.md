# Dazzle Design Studio

Hier is een uitgebreide prompt die goed werkt in Lovable. Hij stuurt sterk op de uitstraling én de structuur zonder de AI te veel te beperken.



Prompt voor Lovable

Create a premium, award-worthy website for a digital web design agency called Web Agency Twente.

The company is technically run by one freelancer, but the brand should always communicate in the “we / our” voice as if it is a creative digital agency with a small team.

Technical

Build with React + Next.js + Tailwind CSS.

Use Framer Motion for animations.

The design should feel like an Awwwards nominee while remaining highly usable.

Every section should contain subtle movement so the page never feels static.

The final impression should be:

“This agency clearly understands modern digital design.”

Visitors should immediately trust the quality of the agency based on the website alone.



Extra toevoeging voor nóg meer impact (onderaan de prompt):

Important: Do not create a generic SaaS landing page. Make this website feel unique, artistic and memorable. Use oversized layouts, asymmetrical compositions, overlapping sections, animated typography, bold color blocking, premium motion design and immersive scrolling. Every scroll should reveal something surprising while maintaining excellent usability and readability.
